# Icon

Icono de trazo de 24 × 24 en `currentColor` para la navegación, los botones y los estados.

- Props: `name` (uno de los nombres de la vista previa), `size` (16 por defecto), `title` (lo convierte en una imagen accesible) y `className`.
- El color se hereda: colorea el elemento padre con `ink-muted` o con un token de estado.
- Conjunto provisional propio, compatible en nombres con Lucide. No combines iconos rellenos con iconos de trazo.
