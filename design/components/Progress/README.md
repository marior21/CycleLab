# Progress

Barra de progreso hacia un objetivo (CTL, salida más larga, desnivel semanal).

- Props: `label`, `valueLabel` (texto con los dos valores), `value`, `max` y `tone`.
- El tono identifica el objetivo (Soplao BTT `speed`, La Cantabrona `z4`), no el grado de avance.
- Escribe siempre el valor y el objetivo en `valueLabel`: la barra sola no basta.
