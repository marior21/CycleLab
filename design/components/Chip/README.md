# Chip

Filtro conmutable de selección múltiple (tipos de actividad, temporadas) y sugerencia del chat.

- Props: `active`, `onClick`, `color` (token de tono para el punto), `count` y `children`.
- El punto de color identifica la categoría y el texto siempre la nombra.
- En el entrenador IA, los chips sin `color` son sugerencias de pregunta.
