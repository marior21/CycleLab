# Panel

Contenedor de sección con título, subtítulo y acciones. Es el único nivel de superficie sobre `bg-000`.

- Props: `title`, `subtitle`, `actions` (nodos a la derecha), `flush` (sin padding lateral, para tablas), `style`, `className` y `children`.
- No anides un Panel dentro de otro. Para subdividir, usa filetes `line`.
- Una tabla dentro de un Panel va con `flush`.
