# Badge

Etiqueta compacta para tipo de actividad, zona, estado o dato de referencia.

- Props: `tone` (token: `z1`…`z7`, `success`, `warning`, `danger`, `info`, `speed`…), `variant` (`outline`), `title` y `children`.
- El tono solo colorea el punto: el texto va siempre en `ink`, así que se lee igual en todos los tonos.
- `outline` con borde discontinuo se reserva para avisos meta («Datos de demostración», «sin configurar»).
